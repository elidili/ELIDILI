## راه‌اندازی روی Vercel

### قدم ۱ - آپلود پروژه
1. برو به vercel.com
2. ثبت‌نام کن
3. روی "Add New Project" کلیک کن
4. این فولدر رو آپلود کن

### قدم ۲ - تنظیم API Key
در Vercel داشبورد:
1. Settings → Environment Variables
2. اضافه کن: REACT_APP_ANTHROPIC_KEY = your_key

### قدم ۳ - Deploy
کلیک Deploy - تمام!
